# 럭키팡: 숫자던전 v3 - 수의 범위와 어림하기

초등학교 5학년 2학기 1단원 학습 흐름을 바탕으로 만든 독립형 카드 배틀 프로젝트입니다. 문제에 사용하는 수는 자연수로 제한했습니다.

## 학습 순서

1. 이상과 이하
2. 초과와 미만
3. 올림과 버림
4. 반올림
5. 종합

각 구역은 대화형 개념학습과 보스 전투로 구성됩니다. 보스를 물리치거나 집중력이 모두 소진될 때까지 전투가 이어지며, 전투는 `퀴즈 → 행동력 보상 → 카드 액션 → 보스 행동` 순서로 진행됩니다. 문제는 시드 기반으로 무작위 생성되며 보기 5개 중 정답 3개, 오답 2개, 럭키 정답 1개, 폭탄 오답 1개를 보장합니다. 모든 선택지에는 정답 근거 또는 오개념 해설이 포함됩니다.

## 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm run test:quiz
npm run test:battle
```
